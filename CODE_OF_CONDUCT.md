# Code of Conduct

## Our pledge

We are committed to making participation in this project a respectful, constructive, and harassment-free experience for everyone, regardless of background or identity.

## Expected behavior

- Be respectful and assume good faith.
- Give and receive technical feedback constructively.
- Focus discussion on evidence, interoperability, safety, and learning.
- Respect privacy; do not publish credentials, customer data, or private reports.

## Unacceptable behavior

Harassment, insults, discrimination, threats, doxxing, unwanted sexual attention, and publication of private information are not acceptable. Deliberately submitting unsafe configurations as if validated is also contrary to the project’s technical standards.

## Scope and enforcement

This code applies in repository issues, pull requests, reviews, and project-related spaces. Maintainers may edit or remove content and close participation that violates it. To report a concern, contact the maintainers through the repository’s GitHub page; no personal contact details are specified here.

This policy is adapted from the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/ (English source). It is not a claim of project affiliation with the Contributor Covenant project.
