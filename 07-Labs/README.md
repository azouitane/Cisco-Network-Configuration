# Labs Cisco

Tous les labs sont `REQUIRES LAB VALIDATION`. Les configurations sont relues statiquement et visent une syntaxe IOS pédagogique souvent disponible dans Packet Tracer, sans garantir la compatibilité de chaque modèle simulé. Aucun fichier `.pkt` ni résultat d’exécution n’est fourni.

| Lab | Niveau | Notions |
|---|---|---|
| [01 — Réseau de base](01-Basic-Network/README.md) | Débutant | Adressage, switch, SSH |
| [02 — VLAN / Inter-VLAN](02-VLAN-InterVLAN/README.md) | Débutant + | VLAN, trunk 802.1Q, router-on-a-stick |
| [03 — Routage statique](03-Static-Routing/README.md) | Intermédiaire | Routes statiques et défaut |
| [04 — OSPF](04-OSPF/README.md) | Intermédiaire | OSPFv2 area 0 |
| [05 — NAT/PAT](05-NAT-PAT/README.md) | Intermédiaire | PAT overload, réseau externe simulé |
| [06 — ACL](06-ACL-Security/README.md) | Intermédiaire | ACL standard/étendue |
| [07 — DHCP](07-DHCP/README.md) | Débutant + | Pools et relay |
| [08 — STP/EtherChannel](08-STP-EtherChannel/README.md) | Intermédiaire | Root bridge et LACP |

Parcours conseillé : 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08. Chaque répertoire contient le guide, la topologie et les configurations par équipement.
